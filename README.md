# حوكمة البيانات للذكاء الاصطناعي: التدريب والاسترجاع ووصول الوكلاء

Governing Data for AI: Training, Retrieval and Agent Access

مسار التنفيذيين والقادة · أكاديمية سدايا · LDS-DMG-301 · المستوى 300

REPLACE: سطر واحد تحت العنوان: ما يستطيع المشارك فعله بعد المقرر

يقرر المشاركون البيانات التي يجوز لأنظمة الذكاء الاصطناعي التدرب عليها أو استرجاعها أو إتاحتها للوكلاء أو إرسالها إلى نماذج خارجية، ثم يختبرون هذه القرارات على مساعد ووكيل معدَّين مسبقًا يعملان على بيانات اصطناعية. أما مسارات المعالجة فموضوع المقرر DEV-DAT-302، والبيئات المعزولة للوكلاء موضوع المقرر LDS-AIG-302، والبيانات الشخصية وحقوق المؤلف في التدريب موضوع المقرر LDS-AIG-306.

**الصيغة:** ورشة عمل: يومان مع مختبرات على أنظمة ذكاء اصطناعي معدّة مسبقًا

**صفحة المقرر:** https://sdaiaacademy.github.io/lds-dmg-301/

## نواتج التعلم

| | نواتج التعلم | المستوى | الدليل |
|---|---|---|---|
| LO1 | يصنف الاستخدامات المقترحة للبيانات في الذكاء الاصطناعي، بحسب فئة البيانات والغرض والاستضافة، إلى مسموح أو مشروط أو محظور، استنادًا إلى اثني عشر طلبًا من وحدات الأعمال | Applied | مصفوفة أهلية تطابق المفتاح في عشرة طلبات من اثني عشر |
| LO2 | يختبر مساعدًا قائمًا على الاسترجاع بحثًا عن تسرب الصلاحيات (permission leakage)، ويحدد مرشّح وسوم التصنيف الذي يسدّه، على 300 وثيقة موسومة بتصنيفاتها وثلاثة أدوار | Applied | سجلات اختبار التسرب قبل تطبيق المرشّح وبعده |
| LO3 | يهيئ صلاحيات الوكيل لكل أداة بحيث تكون محددة النطاق أو للقراءة فقط أو مشروطة بموافقة، عند التعامل مع وكيل يتصل بخادمَي أدوات | Applied | مواصفة للصلاحيات واختبار مبرمج ناجح |
| LO4 | يراجع شروط مقدمي الخدمة بشأن الاحتفاظ والتدريب على المدخلات وموطن البيانات والحذف، ويقرر فئات البيانات التي يجوز إرسالها، استنادًا إلى شروط اصطناعية لمقدمَي خدمة اثنين | Performance | قائمة تحقق ومذكرة قرار |
| LO5 | يدافع عن معيار لاستخدام البيانات في الذكاء الاصطناعي يتضمن قواعد للتسجيل والاحتفاظ، وعن سجل قرار لحالة واحدة، عند التعامل مع وكيل للرد على المواطنين يستخدم ملفات القضايا | Performance | المعيار وسجل القرار، يُناقَشان أمام لجنة تضم مهندسًا |

## الأدوات

كل سطر قدرة، والأمثلة قابلة للتبديل.

- **فهرس استرجاع مع مرشّحات للبيانات الوصفية:** pgvector, OpenSearch
- **النماذج اللغوية:** نموذج محلي مفتوح الأوزان, واجهة برمجة تطبيقات (API) تجارية
- **وصول الوكلاء إلى الأدوات:** خوادم بروتوكول سياق النموذج (MCP), استدعاء الوظائف المباشر
